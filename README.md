
# PLP Python Week 6 Assignment

## Safe Functions

This assignment demonstrates how to use try and except to handle errors safely in Python.

### Files

- safe_tools.py: Contains three safe functions for division, number conversion, and dictionary lookup.
- README.md: Describes the assignment, project files, and error handling.

### Why can an if check not catch abc on its own?

An if statement can check conditions, but it cannot catch a ValueError raised when converting invalid text into an integer. The try and except blocks are used to catch the error and prevent the program from crashing.
